# AI Usage Report

## Tools Used

During the development of this project, several AI tools were used to support requirement analysis, code generation, and implementation review.

1. **ChatGPT**: ChatGPT was used mainly for discussion and conceptual clarification. It helped explain project requirements, suggest development approaches, and improve understanding of how to structure the Flutter application and overall system workflow.

2. **NotebookLM**: NotebookLM was used to review and interpret the provided instructions and lab materials. It helped summarize and organize assignment requirements to ensure implementation followed the expected workflow.

3. **Gemini 3.1 Pro Preview**: Gemini 3.1 Pro Preview was used as the primary coding assistant. It helped generate Flutter code snippets and supported implementation of features such as GPS location capture, QR code scanning, form handling, and local data storage.

4. **Codex**: Codex was used for code review and quality improvement. It helped analyze generated code, suggest improvements, and keep the structure cleaner and closer to production quality.

## Role of AI in the Project

AI tools were used as assistive tools to support development and understanding. All final implementation decisions, testing, and integration were performed manually by the developer.

The use of AI helped accelerate development while maintaining understanding of the system design and functionality.
